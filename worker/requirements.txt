# Ce que `worker/transcribe.py` demande — et ce qu'il ne demande pas.
#
# **À ne pas installer par réflexe.** Sur la machine de Julien, `WHISPER_PYTHON`
# pointe le venv du diariseur de `~/dev/rythmo-impro/diarizer`, qui porte déjà
# tout ceci : 8,1 Go, dont le modèle `large-v3` et les modèles d'alignement en
# cache. En reconstruire un second reviendrait à retélécharger les mêmes poids
# pour les ranger ailleurs. Ce fichier sert à monter le worker sur une machine
# qui n'a pas ce venv, et à dire noir sur blanc ce dont il dépend.
#
#     python3.10 -m venv venv
#     ./venv/bin/pip install -r worker/requirements.txt
#     WHISPER_PYTHON=$PWD/venv/bin/python
#
# Deux absences volontaires :
#
# - **pas de `pyannote.audio`.** L'itération 0 n'utilise pas les locuteurs
#   (spec §17). C'est pyannote qui exige `HF_TOKEN` et un accord accepté sur le
#   Hub ; les modèles d'alignement de WhisperX, eux, sont publics. Ne pas le
#   tirer, c'est se passer d'un jeton, d'un accord et de deux gigaoctets.
# - **pas de `nvidia-cudnn-cu12` nommément.** Il arrive avec `torch`, et
#   `transcript.ts` pose `LD_LIBRARY_PATH` sur le dossier où pip le range —
#   sans quoi CTranslate2 ne le trouve pas et le chargement du modèle échoue.

# WhisperX 3.8 exige torch 2.8 (CUDA 12.8). Versions vérifiées sur cette machine :
# torch 2.8.0, whisperx 3.8.2, ctranslate2 4.6.1, faster-whisper 1.2.1.
torch>=2.8.0
torchaudio>=2.8.0
whisperx>=3.8.0
